# EVI Electric

EVI Electric app/platform structure.

## Main Features
- User registration and login
- Dashboard
- Recharge / balance section
- VIP levels: VIP0 to VIP5
- Referral system
- Referral income: ₹100 per customer
- Withdrawal section
- UPI / merchant payment option
- Transaction history
- Admin login and admin panel
- User and balance management
- EVI Electric branding and images

## Admin
Admin can manage users, recharge records, withdrawal requests, VIP information and transactions.
